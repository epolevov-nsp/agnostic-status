# Agnostic — страница временной недоступности

Отдельная статическая страница для аварии Yandex Cloud 12 октября 2026 года.
Исходники находятся вне продуктовых репозиториев. Страница не обращается к API
Agnostic и не зависит от CDN, JavaScript, внешних шрифтов или npm-пакетов.

## Источник

Официальная карточка инцидента: [Yandex Cloud, инцидент 2136](https://status.yandex.cloud/ru/incidents/2136).
Текст и отметка времени соответствуют сообщению провайдера от 12 октября 2026,
11:17 МСК, проверенному по официальному статусу при подготовке страницы. Данные статические;
страница не заявляет о сохранности данных, мониторинге или сроке восстановления.
Перед дальнейшим использованием нужно сверить карточку инцидента и обновить
текст, если провайдер сообщил о восстановлении.

## Публикация в Timeweb App Platform

- Тип приложения: HTML/CSS/JS.
- Каталог публикации: `dist` (готовые файлы включены в репозиторий).
- Сборка на платформе, переменные окружения и установка зависимостей не требуются.

Чтобы обновить готовые файлы локально, нужен Node.js 22.12 или новее:

```bash
npm run build
```

Скрипт только копирует HTML, CSS и локальные assets в `dist`. Исходники можно
также разместить на обычном статическом хостинге без сборки.

## Дизайн и доступность

Использованы Agnostic Blue `#006dff`, canvas `#f3f5f8`, основная типографика
Inter из локального WOFF2-файла и оригинальный SVG-значок Agnostic.
Иллюстрация облака, сервера и разъединённого кабеля создана встроенным imagegen,
сохранена в `assets/cloud-connection.webp` и декоративна.
[Промпт и формат файла](ILLUSTRATION.md). Ссылки работают без
JavaScript, имеют видимый keyboard focus; действия имеют высоту от 44px.
Мобильная композиция сохраняет читаемость текста и полную ширину действий.
При `prefers-reduced-motion: reduce` отключены переходы состояний кнопок.
